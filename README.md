# ST Vertex AI PayGo 前端扩展

为 **SillyTavern（酒馆）、Luker 以及 TauriTavern** 打造的一站式扩展！
不仅为 Google Vertex AI 提供 **Standard / Flex / Priority** 服务层级调度，还新增支持了 Google AI Studio 的 **Standard / Flex** 模式，并提供极其详尽的**对话用量统计与费用实时估算**。

安装本扩展后，程序会自动识别你当前运行的客户端环境，并直接复用已有的 Google 认证配置。无需手写复杂的 API 请求头，直接在界面勾选即可享受弹性低价（Flex）或高优先级（Priority）！

## 开发分支：Google OpenAI 兼容桥接

此功能在 `feat/google-openai-bridge` 分支开发，尚未发布。需同时使用该分支的前端与配套后端；旧后端没有桥接能力时，界面会提示升级。

**仅支持 SillyTavern / Luker，不支持 TauriTavern。** 此限制只针对桥接功能，已有的 TauriTavern 原生层级与费用功能保持可用。

桥接默认关闭，供数据库、摘要等插件在自己的 **OpenAI 兼容独立 API** 配置中手动使用。默认将请求发送到 Google 官方 OpenAI 兼容端点；Vertex AI 用户可另外选择 Gemini 格式转换网关。AI Studio 保持原有转发方式。不自动重试、切换账号或回退其他端点，使用官方端点不构成账号免封或合规保证。

### 使用方式

1. 在宿主中配置好 Google AI Studio，或使用服务账号的 Vertex AI Full 模式。Vertex Express/API key 模式暂不支持此桥接。
2. 在扩展设置的 Google OpenAI 兼容桥接面板启用功能。桥接固定启用时的提供商、模型、区域和凭据选择；后续切换主聊天连接不会改变它。需要变更时，点击“更新为当前连接”。
3. 展开“调用配置（URL、密钥、模型）”，将 **Base URL** 和 **桥接 API key** 填入其他插件的独立 API 配置，协议选择 OpenAI Chat Completions。桥接 key 不是 Google key。
4. 模型可填写 `st-current`，代表桥接绑定的模型（不是实时跟随主界面的模型）；也可让调用端通过 `GET /models` 拉取 Google 模型目录，选择其中的具体模型。AI Studio 返回 `gemini-*`，Vertex 返回 `google/gemini-*`；调用时也接受不带 `google/` 的名称，不受绑定模型或 PayGo 名单限制。
5. 用完后关闭。关闭、更新连接或轮换 key 都会取消未完成请求。关闭会撤销桥接 key；轮换 key 后也需要更新其他插件中的 key。

### Vertex 协议与服务层级

展开“Vertex 协议与服务层级”可选择以下设置。运行中修改后点击“应用协议与层级”，尚未启用时则随启用操作一起应用。该分组仅对 Vertex 显示，AI Studio 不增加转换或层级控制。

- **官方 OpenAI 接口（默认）**：继续使用 Google 官方 OpenAI 兼容接口。**Vertex 原生 OpenAI 模式不支持 Flex**；选择 Flex 会明确报错，不会悄悄按 Standard 发送。
- **Gemini 格式转换网关（可选）**：调用方仍使用原有的 OpenAI Base URL 和 key，网关把请求转换为 Vertex `generateContent` / `streamGenerateContent`，再转换回 OpenAI JSON / SSE。支持文本、base64 图片输入、函数工具与工具结果、思考签名和 JSON 结构化输出等常用参数；无法表达的参数会明确报错。不会下载远程图片 URL，也不自动改用其他协议。
- **独立设置（默认）**：选择桥接自己的 Standard / Flex / Priority，不修改主聊天设置。
- **跟随主 API**：每次调用读取 ST/Luker 最近保存的主 Vertex API 层级，优先当前连接配置中的本插件设置，否则使用当前预设设置。修改主层级后须等待宿主保存；“刷新状态”会重新检查。主 API 不是 Vertex 或保存设置无法读取时会明确报错。层级跟随不会改变已绑定的账号、模型或区域。

Flex 和 Priority 要求桥接已绑定的 Vertex 区域为 `global`；若区域不符，请先更改主连接区域再点击“更新为当前连接”。Flex 总请求时限为 30 分钟，请同时调长调用插件的超时。第三方请求体不能覆盖桥接选定的层级。协议或策略修改会取消桥接未完成的请求，Base URL 与 key 保持不变。

多轮工具/思考对话的调用端应保留返回消息的 `extra_content`：工具使用 `extra_content.google.thought_signature`，复杂的 Gemini part 与签名位置由 `extra_content.google.gemini_parts` 保留。流式调用端须合并并保存最终消息中的元数据；若修改消息内容，应同步重建或移除对应元数据，网关会拒绝内容不一致的回传，避免使用错误的签名位置。普通文本调用无需处理这些扩展字段。

### 边界与限制

桥接面板默认仅显示状态、固定连接和启用／关闭／刷新操作。“调用配置”“Vertex 协议与服务层级”“连接管理与 Debug”“桥接 API 日志”“使用说明与限制”各自独立折叠，默认收起；需要时展开。Debug 开启时会在折叠标题中提示。

- 默认固定地址为 `http://127.0.0.1:18443/openai/v1`，只监听运行 ST/Luker 后端的本机回环地址。本机命令行、SDK 和其他服务均可携带桥接 key 调用，并不限于 ST/Luker 插件。默认不开放浏览器跨域调用；其他电脑和公网不能直接连接。ST 部署于远程服务器时，`127.0.0.1` 指服务器，不是手机或浏览器所在设备。
- 桥接连接配置和访问 key 只保存在后端内存中。**重启宿主后默认关闭，需要重新启用并更新 key；固定地址保持不变。** 刷新网页可读取当前后端状态。
- 宿主不能提供活动凭据 ID 时，桥接绑定凭据快照；检测到活动凭据改变或删除后会停止请求，需手动更新连接，不会自动使用新账号。
- 支持 `/models` 和 `/chat/completions`，包括非流式 JSON 和流式 SSE。官方模式支持范围以 Google 官方兼容端点为准；转换模式还受转换器支持范围限制，模型是否可用由 Google 判断。
- 模型列表每次查询 Google：AI Studio 使用官方 OpenAI `/models`，Vertex 使用官方 `publishers/google/models` 目录并遍历分页。列表筛选 Gemini，排除明确用于 embedding、Live、原生音频和 TTS 的专用模型；保留 `st-current` 和绑定模型。目录不能保证所有模型在当前项目、区域或 Chat Completions 接口可用；不通过真实生成探测权限，也不拼造目录内部版本号。上游查询失败时返回错误，不用静态名单代替。
- 单次请求体上限 16 MiB，总时限通常为 180 秒，Vertex 转换网关的 Flex 为 30 分钟（包含流式输出）；每用户最多 4 个、全局最多 16 个并发请求。网关转换的非流式 JSON 响应上限 8 MiB，SSE 单事件/单行上限 1 MiB；超过转换边界会明确失败，不返回伪造的完成标记。
- 桥接不继承主聊天的提示词、世界书、历史或采样预设；请求参数由调用插件提供。只有 Vertex 显式选择“跟随主 API”时才读取主层级，默认仍为独立 Standard。
- 不支持反向代理连接、任意自定义上游、账号池、失败换号和原生 API 回退。上游错误直接返回调用方；第三方插件自身是否重试，由它的设置决定。
- 桥接请求不计入本扩展现有的主对话费用账本，避免把数据库或摘要的用量归入角色回复。

官方协议参考：[AI Studio OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[Vertex AI OpenAI 兼容接口](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/start/openai)。

### 本机浏览器 Debug

开发检测时，在桥接面板开启 **Debug：允许 localhost 浏览器调用**。此选项默认关闭、仅保存在当前服务器会话中；仍需填写桥接 API key，不会提供免鉴权访问。前后端须一并更新，旧后端会提示升级。

允许来源为 `http://` 或 `https://` 的 `localhost`、`127.0.0.1`、`[::1]` 页面（任意端口）；不放行公网网页或 `file://` 页面。每个用户的桥接 key 独立检查此开关。修改 Debug 设置会取消当前桥接的未完成请求。

例如在本机开发网页中调用，替换为面板显示的地址和 key：

```js
const baseUrl = 'http://127.0.0.1:18443/openai/v1';
const apiKey = 'YOUR_BRIDGE_API_KEY';
const response = await fetch(`${baseUrl}/models`, {
    headers: { Authorization: `Bearer ${apiKey}` },
});
const models = await response.json();
console.log(models);
```

Debug 只开放桥接数据接口的本机跨域访问，不开放 ST 管理接口，不改变 Google 上游。浏览器自身的本地网络权限限制仍可能需要在浏览器中处理。

### 固定端口与 API 日志

后端首次启动会在 ST/Luker 根目录创建 `st-vertex-paygo-bridge.json`，默认内容为 `{"port":18443}`。需要改端口时修改该文件并重启，允许 1024–65535。多实例请使用不同端口。端口占用或配置错误会阻止桥接启用，不自动换端口，也不影响主聊天 PayGo 传输。

桥接面板提供独立的 **API 日志**：手动刷新查看请求体原文、实际转发的请求体、响应体和错误，包括 SSE 流式正文；可以清空自己的日志。日志包含提示词及模型输出，请仅在需要时分享相关片段。日志按宿主用户隔离，跨重启保留，有容量上限；过长正文会显示截断标记，中断请求也会标记。不会记录认证头，已知桥接及上游凭据会脱敏。它与现有管理员诊断日志、主聊天用量账本分开。

## 🌟 主要功能

- **多层级调度与 PayGo 开关**：
  - Vertex AI：支持 Standard / Flex / Priority，并可单独开启 `PayGo-only`（强制按量计费，避开预配额限制）。
  - Google AI Studio：新增支持 Standard / Flex 弹性推理。
- **一键同步 Global 区域**：选择 Vertex Flex / Priority 时，Google 官方要求必须使用 `global` 区域，扩展会弹窗贴心协助你一键切换（AI Studio 无需设置区域）。
- **💰 实时对话费用估算**：点击输入框左侧的“魔法棒 🪄”菜单，即可查看当前对话的 Token 用量、缓存命中率以及消费金额小计。
- **🏷️ 单条回复费用**：默认在消息内容底部显示这一版回复的估算花费（如 `≈ $0.02331`），也可切换到消息头、头像下方或隐藏。点击金额还能弹出**详细用量卡片**，查看输入、输出、思维链（Reasoning）Token、耗时与生成速率。
- **🔄 动态模型与价格同步**：启动及运行中每 6 小时自动同步最新支持的模型名单与官方计费价格，断网时自动启用本地离线快照，也支持手动自定义单价。
- **🛡️ 智能防扣错机制**：严格校验模型、区域与层级组合；后端异常或 Flex 排队失败时直接拦截，**绝不静默回退到贵价通道**。
- **📱 跨客户端适配**：同时完美兼容网页版酒馆、Luker 以及 TauriTavern 桌面/移动客户端。

### 第一步：安装后端插件（⚠️ 仅 SillyTavern / Luker 需要；TauriTavern 请跳过此步）

1. 彻底关闭 SillyTavern 或 Luker。
2. 下载并解压 [`ST-Vertex-PayGo-Server`](https://github.com/mananekoha114/ST-Vertex-PayGo-Server) 后端仓库，放入酒馆根目录的 `plugins` 文件夹下：
   ```text
   <酒馆根目录>/plugins/ST-Vertex-PayGo-Server/
   ```
3. 打开酒馆根目录下的 `config.yaml`，确认已开启服务端插件支持：
   ```yaml
   enableServerPlugins: true
   ```
4. 重新启动 SillyTavern 或 Luker。

> ⚠️ **TauriTavern 用户**：请直接跳过第一步，**完全不需要安装后端插件或 Node.js**！

### 第二步：安装前端扩展（所有客户端通用）

1. 打开酒馆 / TauriTavern，进入 **扩展程序（三块积木图标 🧩） → 安装扩展程序**。
2. 粘贴本仓库 Git 地址：`https://github.com/mananekoha114/ST-Vertex-PayGo`，点击安装。
3. 安装完成后，刷新网页或重启客户端即可。无需执行任何 npm 命令。

## 🕹️ 使用指南

### 1. 开启设置面板

首先在 **API 连接设置（插头图标 🔌） → Chat Completion** 中，选择 **Google Vertex AI** 或 **Google AI Studio**，并填好认证与模型。然后根据你使用的软件进入设置：

- **SillyTavern / Luker 用户**：在当前 API 连接设置界面下方，即可看到新增的 **“Vertex AI PayGo”** 或 **“Google AI Studio Flex”** 设置卡片。
- **TauriTavern 用户**：点击顶部导航栏进入 **扩展设置 → Vertex AI PayGo · TauriTavern**，点击标题即可展开配置面板。
  *(注：TauriTavern 支持分别为“当前连接”或具体的“Agent 模型目标 (Model Target)”指定不同的层级)*。

### 2. 选择服务层级

| 服务商 | 选项 | 说明与注意事项 |
| :--- | :--- | :--- |
| **Vertex AI** | **Standard** | 标准常规层级，走正常计费通道。 |
| **Vertex AI** | **PayGo-only** | 强制使用共享按量计费通道（绕过预配配额），可与 Flex / Priority 叠加开启。 |
| **Vertex AI** | **Flex** | 弹性调度（成本极低，排队时间较长）。**仅限特定模型，且区域必须设为 `global`**。 |
| **Vertex AI** | **Priority** | 高优先级调度。**仅限特定模型，且区域必须设为 `global`**。实际由 Google 动态调度。 |
| **AI Studio** | **Standard** | 官方默认的标准层级。 |
| **AI Studio** | **Flex** | 弹性推理层级。**仅限付费账号及特定支持的模型**（无需配置区域）。 |

> 📌 **检查状态**：SillyTavern / Luker 用户请确认面板上的“服务端插件状态”显示为 **就绪（Ready）**；TauriTavern 用户走系统原生接口，无需此状态。

### 3. 如何彻底切回默认 / 卸载扩展？

- 如果想恢复原本模式，请在面板中选择 **Standard** 并**关闭 PayGo-only**。
- **特别注意（TauriTavern）**：由于 TauriTavern 会把参数写入软件原生的附加参数中，因此在卸载或禁用扩展前，**请务必手动先改回 Standard**，否则旧的层级参数仍会保留在应用配置里。

## 💵 对话费用与用量估算功能

本扩展提供了极其详尽的用量追踪能力，你可以从两个地方随时掌握 Token 与花销：

### 1. 单条回复费用卡片
AI 回复默认在消息内容底部（正文、媒体和附件之后）显示这一版回复的估算花费（例如：`≈ $0.02331`）：
- **显示位置**：在 **API 设置 → Vertex AI / Google AI Studio 的 PayGo 面板 → 消息费用位置** 中选择“消息底部（默认）”“消息头”“头像下方”或“隐藏”。TauriTavern 在 **扩展设置 → 本扩展对应面板** 中提供相同选项。
- **立即生效并保存**：位置是全局显示偏好，切换 API 来源、连接或对话不会改变它，刷新页面后保留；隐藏只关闭入口，不停止费用记录。
- **美化适配**：选择的消息头或头像栏被隐藏、缺失时，入口回退到消息内容底部；恢复可见后回到选定位置。底部入口不写入正文，避免正文更新覆盖它。特殊美化仍可通过位置选项调整。
- **点击金额**：即可弹开详细卡片，直观查看本条消息的**上下文输入、未缓存输入、缓存命中、生成输出、推理思维链（Reasoning）Token、总耗时与生成速率 (Tokens/s)**！
- **多版本滑动与续写**：每次滑动重新生成（Swipe），金额会自动关联并切换；使用“续写”功能时，耗时与花费会自动累计合并。
- **数据本地保存**：所有的用量快照会随对话历史保存在本地，哪怕重新刷新页面也能直接查看。

### 2. 魔法棒菜单中的“总账本”
点击输入框左侧的 **魔法棒 🪄 → 对话费用估算**，可以调出全局账本窗口：
- 查看当前对话累计的总估算花费、最近一次请求花费、总请求次数以及总体缓存命中率。
- **数据纯本地统计**：仅保存在你的本地浏览器/数据目录中，绝不上传云端，查询账本也不会二次触发 Google API 扣费。

> ⚠️ **费用估算精度说明（防坑必看）**：
> 1. 本地金额是根据 Google 官方单价公式进行的**理论估算**，并非 Google 官方出具的扣款账单（未计算赠金折扣、具体币种税费及长上下文存储租金）。
> 2. **TauriTavern 非流式模式**：由于 Tauri 客户端在非流式模式下可能不返回思维链（思考）Token，因此非流式请求可能会被标记为“部分估算”，估算结果可能会略低于实际情况。
> 3. **Agent 自动循环**：TauriTavern 的原生 Agent 内部循环耗费暂未纳入单条卡片，请勿直接用单次小计代表整个 Agent 任务的总花费。

## 🤖 动态模型名单与价格同步

本插件仅针对 Vertex AI 与 AI Studio 的官方 **`gemini-*` 原生系列模型** 生效：

- **官方支持模型**：界面会只开放该模型实际支持的层级供你选择。
- **未来新出的 Gemini 模型**：如果 Google 推出了全新模型，而插件尚未收录，界面会显示黄色“未验证”提醒，但**依然允许你发送请求**，交由 Google 官方作最终验证。
- **非 Gemini 模型（Claude / Llama 等）**：官方不支持类型切换，直接走酒馆原版通道，不经过本插件。

### 价格与名单更新机制
- **离线安全**：内置完备的离线模型支持快照。在完全断网或局域网环境下，酒馆也能秒开，不受任何网络阻塞。
- **后台自动轮询**：联网状态下，扩展每隔 6 小时会在后台静默拉取最新的官方核验名单与价格；你也可以在费用面板中点击“立即更新”。
- **自定义单价覆盖**：支持手动填写输入、输出和缓存单价。只要你填写了自定义价格，就会优先使用你的设定，在线更新绝不会覆盖你的自定义配置。

## ❓ 常见问题 (FAQ)

### Q: 为什么界面找不到设置面板，或提示不兼容？
**A**: 
- **SillyTavern / Luker**：必须先在 API 连接设置中把服务商切换为 **Google Vertex AI** 或 **Google AI Studio**，面板才会显现。
- **TauriTavern**：面板位于 **扩展设置 → Vertex AI PayGo · TauriTavern**，默认是折叠的，点击标题即可展开。如果提示缺少接口，说明当前所用的 Tauri 构建版本未开启第三方扩展或附加参数权限。

### Q: “服务端插件状态”始终显示未就绪（仅 ST / Luker）？
**A**: 请按顺序检查：
1. 后端文件夹是否放在了 `<酒馆根目录>/plugins/ST-Vertex-PayGo-Server/`。
2. 酒馆根目录的 `config.yaml` 中是否已将 `enableServerPlugins` 设为 `true`。
3. 修改配置或放好文件后，必须**彻底关闭并重新启动酒馆终端**。

### Q: 为什么无法勾选 Flex 或 Priority 选项？
**A**:
1. 检查当前模型 ID 是否以 `gemini-` 开头。
2. 检查所选模型是否支持该层级（不支持的模型会被置灰禁用）。
3. AI Studio 官方不提供 Priority 模式。
4. Vertex AI 的 Flex / Priority 强制要求区域设为 `global`，请按照弹窗提示切换区域。

### Q: 为什么非流式模式下的回复显示“部分估算”？
**A**: 这是正常现象。在 TauriTavern 等环境下，非流式响应不会回传思考过程产生的 Token 数量，为了避免误导，插件会严谨地将其标注为“部分估算”，而不会直接算作 0 元。
