# ST Vertex AI PayGo 前端扩展

为 **SillyTavern（酒馆）、Luker 以及 TauriTavern** 打造的一站式扩展！
不仅为 Google Vertex AI 提供 **Standard / Flex / Priority** 服务层级调度，还支持 Google AI Studio 的 **Standard / Flex** 模式，并提供极其详尽的**对话用量统计与费用实时估算**。

安装本扩展后，程序会自动识别你当前运行的客户端环境，并直接复用已有的 Google 认证配置。无需手写复杂的 API 请求头，直接在界面勾选即可享受弹性低价（Flex）或高优先级（Priority）！

当前版本 **v0.6.0** · [更新日志](CHANGELOG.md) · [安装与更新脚本](INSTALL.md) · [Gemini 4 Argon 兼容说明](GEMINI4.md)

---

## 🌟 主要功能

- **多层级调度与 PayGo 开关**：
  - Vertex AI：支持 Standard / Flex / Priority，并可单独开启 `PayGo-only`（强制按量计费，避开预配额限制）。
  - Google AI Studio：支持 Standard / Flex 弹性推理，并可使用宿主中填写的反向代理。
- **一键同步 Global 区域**：选择 Vertex Flex / Priority 时，Google 官方要求必须使用 `global` 区域，扩展会弹窗协助你一键切换（AI Studio 无需设置区域）。
- **💰 实时对话费用估算**：点击输入框左侧的“魔法棒 🪄”菜单，即可查看当前对话的 Token 用量、缓存命中率以及消费金额小计。
- **🏷️ 单条回复费用**：默认在消息内容底部显示这一版回复的估算花费（如 `≈ $0.02331`），也可切换到消息头、头像下方或隐藏。点击金额还能弹出**详细用量卡片**，查看输入、输出、思维链（Reasoning）Token、耗时与生成速率。
- **🔄 动态模型与价格同步**：启动及运行中每 6 小时自动同步最新支持的模型名单与官方计费价格，断网时自动启用本地离线快照，也支持手动自定义单价。
- **🔌 Google OpenAI 兼容桥接**：为数据库、摘要等插件提供本机 OpenAI Chat Completions 接口，复用宿主中的 Google 凭据（仅 SillyTavern / Luker）。
- **🧩 Gemini 4 Argon 原生兼容**：为原生 Gemini 来源补齐思考配置、媒体、签名与长输出续传（仅 SillyTavern / Luker）。
- **🛡️ 智能防扣错机制**：严格校验模型、区域与层级组合；后端异常或 Flex 排队失败时直接拦截，**绝不静默回退到贵价通道**。
- **🧰 面板内维护**：管理员可在扩展菜单中查看日志、执行前后端配套更新、恢复 PayGo 数据快照。
- **📱 跨客户端适配**：同时兼容网页版酒馆、Luker 以及 TauriTavern 桌面/移动客户端；设置菜单适配桌面与手机布局。

## 📦 版本与安装要求

当前前端版本为 **v0.6.0**。SillyTavern / Luker 须将前端扩展与配套后端**一并更新到同一版本**，随后重启宿主并刷新页面；旧后端缺少某项能力时，界面会隐藏对应入口或提示升级。

| 客户端程序 | 版本及运行环境 | 需要安装哪些组件？ | 底层请求通道 |
| :--- | :--- | :--- | :--- |
| **SillyTavern** | ≥ 1.16.0（已测试 1.16 / 1.17 / 1.18）；Node.js ≥ 20 | **本前端扩展** + **后端插件 ≥ 0.6.0** | 后端回环代理 |
| **Luker** | ≥ 2.7.0（release 分支）；Node.js ≥ 20 | **本前端扩展** + **后端插件 ≥ 0.6.0** | 后端回环代理 |
| **TauriTavern** | ≥ 2.3.0（需支持第三方扩展及附加参数） | **仅需安装本前端扩展！**（无需后端） | Tauri 原生通道 |

> 💡 **请先配置好账号**：请确保已在酒馆中配好 Vertex AI（快速模式 Key 或服务账号 json 均可）或已绑卡的 Google AI Studio 付费账号。

安装方式任选其一：

- **一条命令自动安装（推荐，SillyTavern / Luker，含 Termux）**：已配置好宿主环境的用户可使用 [在线安装或本地安装脚本](INSTALL.md)，支持 PowerShell `irm | iex` 和 Termux / Linux / macOS `curl | sh`，一次安装前端与后端，并备份、更新配置。脚本不适用于 TauriTavern。
- **手动安装**：按下面两步操作。

### 第一步：安装后端插件（⚠️ 仅 SillyTavern / Luker 需要；TauriTavern 请跳过此步）

1. 彻底关闭 SillyTavern 或 Luker。
2. 下载并解压 [`ST-Vertex-PayGo-Server`](https://github.com/mananekoha114/ST-Vertex-PayGo-Server) 后端仓库，放入酒馆根目录的 `plugins` 文件夹下：
   ```text
   <酒馆根目录>/plugins/ST-Vertex-PayGo-Server/
   ```
3. 打开酒馆根目录下的 `config.yaml`，确认已开启服务端插件支持：
   ```yaml
   enableServerPlugins: true
   ```
4. 重新启动 SillyTavern 或 Luker。

> ⚠️ **TauriTavern 用户**：请直接跳过第一步，**完全不需要安装后端插件或 Node.js**！

### 第二步：安装前端扩展（所有客户端通用）

1. 打开酒馆 / TauriTavern，进入 **扩展程序（三块积木图标 🧩） → 安装扩展程序**。
2. 粘贴本仓库 Git 地址：`https://github.com/mananekoha114/ST-Vertex-PayGo`，点击安装。
3. 安装完成后，刷新网页或重启客户端即可。无需执行任何 npm 命令。

### 更新插件

- **一条命令更新**：使用 [专用更新命令](INSTALL.md#一条命令更新)，保留宿主配置并在更新前备份。`main` 默认更新到最新可达 tag（包含预发布）；其他分支按 commit 判断更新。没有新版本时跳过替换，已领先最新 tag 的官方提交不会自动回退。
- **面板内更新**：前后端均由宿主界面安装的用户，管理员可在 **扩展程序 → ST-Vertex-PayGo →「常规」→ 日志与维护** 中检查并执行配套更新。两个组件一起更新到与命令行相同的发布版本，保留跟踪分支、保护本地修改、替换前备份；不需要系统 Git 或 npm。完成后需重启宿主并刷新页面。后端版本过旧或当前账号不是管理员时，不显示该入口。详见 [面板内更新](INSTALL.md#面板内更新)。
- **TauriTavern**：在宿主的扩展管理中更新前端扩展即可。

## 🕹️ 使用指南

### 1. 设置入口

首先在 **API 连接设置（插头图标 🔌） → Chat Completion** 中，选择 **Google Vertex AI** 或 **Google AI Studio**，并填好认证与模型。

**SillyTavern / Luker**：

- **服务层级卡片**：服务层级切换、PayGo-only、服务端状态和重试按钮位于当前 API 连接设置的 **“Vertex AI PayGo”** 或 **“Google AI Studio Flex”** 卡片中。
- **扩展菜单**：其余设置统一收在 **扩展程序 → ST-Vertex-PayGo** 折叠菜单内，切换 API 来源后仍可访问。菜单按三个标签页划分，会记住上次打开的标签页；窄屏下标签与按钮自动铺满，触屏控件加大。

| 标签页 | 内容 |
| :--- | :--- |
| **常规** | 消息费用显示位置与最近楼层范围；服务端状态、查看 / 保存日志、恢复数据、检查更新 |
| **桥接** | [Google OpenAI 兼容桥接](#-google-openai-兼容桥接) 的启用、调用配置、协议与层级、Debug 与 API 日志 |
| **价格** | 手动单价、恢复自动价格、更新支持列表和价格；切换到此页时自动填入当前连接 |

**TauriTavern**：点击顶部导航栏进入 **扩展设置 → ST-Vertex-PayGo**。服务层级与消息费用显示位于「常规」标签页，价格设置位于「价格」标签页。TauriTavern 支持分别为“当前连接”或具体的“Agent 模型目标（Model Target）”指定不同的层级。

### 2. 选择服务层级

| 服务商 | 选项 | 说明与注意事项 |
| :--- | :--- | :--- |
| **Vertex AI** | **Standard** | 标准常规层级，走正常计费通道。 |
| **Vertex AI** | **PayGo-only** | 强制使用共享按量计费通道（绕过预配配额），可与 Flex / Priority 叠加开启。 |
| **Vertex AI** | **Flex** | 弹性调度（成本极低，排队时间较长）。**仅限特定模型，且区域必须设为 `global`**。 |
| **Vertex AI** | **Priority** | 高优先级调度。**仅限特定模型，且区域必须设为 `global`**。实际由 Google 动态调度。 |
| **AI Studio** | **Standard** | 官方默认的标准层级。 |
| **AI Studio** | **Flex** | 弹性推理层级。**仅限付费账号及特定支持的模型**（无需配置区域）。 |

> 📌 **检查状态**：SillyTavern / Luker 用户请确认 API 面板中的“服务端插件状态”显示为 **就绪（Ready）**；TauriTavern 用户走系统原生接口，无需此状态。

### 3. AI Studio 反向代理（SillyTavern / Luker）

直接使用宿主 API 设置中的“反向代理”地址与代理密码，无需在扩展中重复填写：

- 支持 HTTP / HTTPS 和带路径前缀的基址（如 `https://proxy.example/gemini`）。宿主会追加 `/v1beta/models/...` 等原生 Gemini 路径，不要额外填写该后缀。
- 代理密码用于上游认证，可以留空；代理启用时不读取 Google 官方密钥。
- Standard / Flex、流式与非流式均经过插件的用量采集；Flex 要求上游支持 `service_tier: "flex"`。
- 适用于主聊天及后台原生 Gemini 请求。独立的 OpenAI 兼容桥接仍使用官方端点；Vertex 自定义反代仍不支持。

### 4. 如何彻底切回默认 / 卸载扩展？

- 如果想恢复原本模式，请在 API 面板中选择 **Standard** 并**关闭 PayGo-only**。TauriTavern 在扩展菜单的「常规」标签页中操作。
- **特别注意（TauriTavern）**：由于 TauriTavern 会把参数写入软件原生的附加参数中，因此在卸载或禁用扩展前，**请务必手动先改回 Standard**，否则旧的层级参数仍会保留在应用配置里。

## 💵 对话费用与用量估算

本扩展提供了极其详尽的用量追踪能力，你可以从两个地方随时掌握 Token 与花销。

### 1. 单条回复费用卡片

AI 回复默认在消息内容底部（正文、媒体和附件之后）显示这一版回复的估算花费（例如：`≈ $0.02331`）：

- **显示位置**：在 **扩展程序 → ST-Vertex-PayGo →「常规」→ 消息费用位置** 中选择“消息底部（默认）”“消息头”“头像下方”或“隐藏”。TauriTavern 位于同一菜单的同一位置。
- **立即生效并保存**：位置是全局显示偏好，切换 API 来源、连接或对话不会改变它，刷新页面后保留；隐藏只关闭入口，不停止费用记录。
- **最近楼层范围**：费用入口默认仅显示最近 20 层，可在同一位置调整为 1–1000 层；按聊天楼层计数，包含用户和系统消息。窗口外的历史费用继续保留，返回显示范围后可查看；只汇总窗口内的回复入口，避免超长聊天每次刷新都遍历全部消息。
- **美化适配**：选择的消息头或头像栏被隐藏、缺失时，入口回退到消息内容底部；恢复可见后回到选定位置。底部入口不写入正文，避免正文更新覆盖它。
- **点击金额**：弹开详细卡片，查看本条消息的**上下文输入、未缓存输入、缓存命中、生成输出、推理思维链（Reasoning）Token、总耗时与生成速率（Tokens/s）**。
- **多版本滑动与续写**：每次滑动重新生成（Swipe），金额会自动关联并切换；使用“续写”功能时，耗时与花费会自动累计合并。
- **数据本地保存**：用量快照随对话历史保存在本地，刷新页面后也能直接查看。

### 2. 魔法棒菜单中的“总账本”

点击输入框左侧的 **魔法棒 🪄 → 对话费用估算**，可以调出全局账本窗口：

- 查看当前对话累计的总估算花费、最近一次请求花费、总请求次数以及总体缓存命中率。
- **数据纯本地统计**：仅保存在你的本地浏览器 / 数据目录中，绝不上传云端，查询账本也不会二次触发 Google API 扣费。

> ⚠️ **费用估算精度说明（防坑必看）**：
> 1. 本地金额是根据 Google 官方单价公式进行的**理论估算**，并非 Google 官方出具的扣款账单（未计算赠金折扣、具体币种税费及长上下文存储租金）。
> 2. **TauriTavern 非流式模式**：由于 Tauri 客户端在非流式模式下可能不返回思维链（思考）Token，非流式请求可能会被标记为“部分估算”，估算结果可能略低于实际情况。
> 3. **Agent 自动循环**：TauriTavern 的原生 Agent 内部循环耗费暂未纳入单条卡片，请勿直接用单次小计代表整个 Agent 任务的总花费。
> 4. **桥接请求**：OpenAI 兼容桥接的调用不计入主对话费用账本，避免把数据库或摘要的用量归入角色回复。

## 🤖 动态模型名单与价格同步

本插件仅针对 Vertex AI 与 AI Studio 的官方 **`gemini-*` 原生系列模型** 生效：

- **官方支持模型**：界面只开放该模型实际支持的层级供你选择。
- **未来新出的 Gemini 模型**：如果 Google 推出了全新模型，而插件尚未收录，界面会显示黄色“未验证”提醒，但**依然允许你发送请求**，交由 Google 官方作最终验证。
- **非 Gemini 模型（Claude / Llama 等）**：官方不支持层级切换，直接走酒馆原版通道，不经过本插件。

价格与名单的更新机制：

- **离线安全**：内置离线模型支持快照。在完全断网或局域网环境下，酒馆也能正常打开，不受网络阻塞。
- **后台自动轮询**：联网状态下，扩展每隔 6 小时在后台静默拉取最新的官方核验名单与价格；也可以在 **扩展程序 → ST-Vertex-PayGo →「价格」** 中点击“更新支持列表和价格”。
- **自定义单价覆盖**：在「价格」标签页中手动填写输入、输出和缓存单价。只要填写了自定义价格，就会优先使用你的设定，在线更新不会覆盖自定义配置。

## 🔌 Google OpenAI 兼容桥接

> **仅支持 SillyTavern / Luker，不支持 TauriTavern。** 此限制只针对桥接功能，TauriTavern 的原生层级与费用功能保持可用。

桥接默认关闭，供数据库、摘要等插件在自己的 **OpenAI 兼容独立 API** 配置中手动使用。默认将请求发送到 Google 官方 OpenAI 兼容端点；Vertex AI 用户可另外选择 Gemini 格式转换网关。不自动重试、切换账号或回退其他端点；使用官方端点不构成账号免封或合规保证。

官方协议参考：[AI Studio OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[Vertex AI OpenAI 兼容接口](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/start/openai)。

### 使用方式

1. 在宿主中配置好 Google AI Studio，或使用服务账号的 Vertex AI Full 模式。Vertex Express / API key 模式暂不支持此桥接。
2. 在 **扩展程序 → ST-Vertex-PayGo →「桥接」** 中启用。桥接固定启用时的提供商、模型、区域和凭据选择；后续切换主聊天连接不会改变它。需要变更时，点击“更新为当前连接”。
3. 展开“调用配置（URL、密钥、模型）”，将 **Base URL** 和 **桥接 API key** 填入其他插件的独立 API 配置，协议选择 OpenAI Chat Completions。桥接 key 不是 Google key。
4. 模型可填写 `st-current`，代表桥接绑定的模型（不是实时跟随主界面的模型）；也可让调用端通过 `GET /models` 拉取 Google 模型目录，选择其中的具体模型。AI Studio 返回 `gemini-*`，Vertex 返回 `google/gemini-*`；调用时也接受不带 `google/` 的名称，不受绑定模型或 PayGo 名单限制。
5. 用完后关闭。关闭、更新连接或轮换 key 都会取消未完成请求。关闭会撤销桥接 key；轮换 key 后也需要更新其他插件中的 key。

「桥接」页默认只显示状态、固定连接和启用 / 关闭 / 刷新操作。“调用配置”“Vertex 协议与服务层级”“连接管理与 Debug”“桥接 API 日志”“使用说明与限制”各自独立折叠，默认收起；Debug 开启时会在折叠标题中提示。

### Vertex 协议与服务层级

展开“Vertex 协议与服务层级”可选择以下设置。运行中修改后点击“应用协议与层级”，尚未启用时则随启用操作一起应用。该分组仅对 Vertex 显示，AI Studio 不增加转换或层级控制。

| 设置 | 选项 | 说明 |
| :--- | :--- | :--- |
| 协议 | **官方 OpenAI 接口（默认）** | 使用 Google 官方 OpenAI 兼容接口。**Vertex 原生 OpenAI 模式不支持 Flex**；选择 Flex 会明确报错，不会悄悄按 Standard 发送。 |
| 协议 | **Gemini 格式转换网关** | 调用方仍使用原有的 Base URL 和 key，网关把请求转换为 Vertex `generateContent` / `streamGenerateContent`，再转换回 OpenAI JSON / SSE。支持文本、base64 图片输入、函数工具与工具结果、思考签名和 JSON 结构化输出等常用参数；无法表达的参数会明确报错。不下载远程图片 URL，也不自动改用其他协议。 |
| 层级来源 | **独立设置（默认）** | 选择桥接自己的 Standard / Flex / Priority，不修改主聊天设置。 |
| 层级来源 | **跟随主 API** | 每次调用读取 ST / Luker 最近保存的主 Vertex API 层级：优先当前连接配置中的本插件设置，否则使用当前预设设置。修改主层级后须等待宿主保存，“刷新状态”会重新检查。主 API 不是 Vertex 或保存设置无法读取时会明确报错。不会改变已绑定的账号、模型或区域。 |

- Flex 和 Priority 要求桥接已绑定的 Vertex 区域为 `global`；若区域不符，请先更改主连接区域，再点击“更新为当前连接”。
- Flex 总请求时限为 30 分钟，请同时调长调用插件的超时。第三方请求体不能覆盖桥接选定的层级。
- 协议或策略修改会取消桥接未完成的请求，Base URL 与 key 保持不变。
- 多轮工具 / 思考对话的调用端应保留返回消息的 `extra_content`：工具使用 `extra_content.google.thought_signature`，复杂的 Gemini part 与签名位置由 `extra_content.google.gemini_parts` 保留。流式调用端须合并并保存最终消息中的元数据；若修改消息内容，应同步重建或移除对应元数据，网关会拒绝内容不一致的回传，避免使用错误的签名位置。普通文本调用无需处理这些扩展字段。

### 地址、端口与状态保存

- **地址**：默认固定为 `http://127.0.0.1:18443/openai/v1`，只监听运行 ST / Luker 后端的本机回环地址。本机命令行、SDK 和其他服务均可携带桥接 key 调用，不限于 ST / Luker 插件。默认不开放浏览器跨域调用；其他电脑和公网不能直接连接。ST 部署于远程服务器时，`127.0.0.1` 指服务器，不是手机或浏览器所在设备。
- **端口**：后端首次启动会在 ST / Luker 根目录创建 `st-vertex-paygo-bridge.json`，默认内容为 `{"port":18443}`。需要改端口时修改该文件并重启，允许 1024–65535；多实例请使用不同端口。端口占用或配置错误会阻止桥接启用，不自动换端口，也不影响主聊天 PayGo 传输。
- **自动恢复**：启用或关闭后，宿主会按用户保存当前开关、固定连接、协议与服务层级、Debug 设置和桥接 API key。**已启用的桥接会在 ST / Luker 下次启动时自动恢复，无需先打开网页；API key 与固定地址保持不变。** 关闭状态也会保存。刷新网页可读取当前后端状态。新安装或没有保存记录时默认关闭。
- **保存位置**：`<用户数据目录>/vertex-paygo/openai-bridge-state.json`，按 `0600` 模式创建；包含桥接 API key，不保存 Google 私钥或访问令牌。
- **凭据**：Google 凭据仍由宿主管理。凭据缺失、本地校验失败，或旧版宿主的绑定凭据已变更时，自动恢复会保持关闭，不会改用当前主聊天连接；可修复凭据后手动启用，或点击“关闭桥接”取消后续恢复。宿主不能提供活动凭据 ID 时，桥接绑定凭据快照，检测到活动凭据改变或删除后会停止请求，需手动更新连接。启动时不向 Google 验证远端授权，实际调用仍可能被拒绝。

### 接口、模型与限额

- 支持 `/models` 和 `/chat/completions`，包括非流式 JSON 和流式 SSE。官方模式的支持范围以 Google 官方兼容端点为准；转换模式还受转换器支持范围限制，模型是否可用由 Google 判断。
- 模型列表每次查询 Google：AI Studio 使用官方 OpenAI `/models`，Vertex 使用官方 `publishers/google/models` 目录并遍历分页。列表筛选 Gemini，排除明确用于 embedding、Live、原生音频和 TTS 的专用模型；保留 `st-current` 和绑定模型。目录不能保证所有模型在当前项目、区域或 Chat Completions 接口可用；不通过真实生成探测权限，也不拼造目录内部版本号。上游查询失败时返回错误，不用静态名单代替。
- 单次请求体上限 16 MiB；总时限通常为 180 秒，Vertex 转换网关的 Flex 为 30 分钟（包含流式输出）；每用户最多 4 个、全局最多 16 个并发请求。网关转换的非流式 JSON 响应上限 8 MiB，SSE 单事件 / 单行上限 1 MiB；超过转换边界会明确失败，不返回伪造的完成标记。
- 桥接不继承主聊天的提示词、世界书、历史或采样预设，请求参数由调用插件提供。只有 Vertex 显式选择“跟随主 API”时才读取主层级。
- 不支持反向代理连接、任意自定义上游、账号池、失败换号和原生 API 回退。上游错误直接返回调用方；第三方插件是否重试，由它自己的设置决定。

### API 日志

「桥接」页提供独立的 **桥接 API 日志**：手动刷新查看请求体原文、实际转发的请求体、响应体和错误，包括 SSE 流式正文；可以清空自己的日志。

- 日志包含提示词及模型输出，请仅在需要时分享相关片段。
- 日志按宿主用户隔离，跨重启保留，有容量上限；过长正文会显示截断标记，中断请求也会标记。
- 不记录认证头，已知桥接及上游凭据会脱敏。它与管理员诊断日志、主聊天用量账本分开。

### 本机浏览器 Debug

开发检测时，在 **连接管理与 Debug** 中开启 **Debug：允许 localhost 浏览器调用**。此选项默认关闭，随桥接配置保存，重启恢复时会保留。仍需填写桥接 API key，不提供免鉴权访问。

- 允许来源为 `http://` 或 `https://` 的 `localhost`、`127.0.0.1`、`[::1]` 页面（任意端口）；不放行公网网页或 `file://` 页面。每个用户的桥接 key 独立检查此开关。
- 修改 Debug 设置会取消当前桥接的未完成请求。
- Debug 只开放桥接数据接口的本机跨域访问，不开放 ST 管理接口，不改变 Google 上游。浏览器自身的本地网络权限限制仍可能需要在浏览器中处理。

例如在本机开发网页中调用（替换为面板显示的地址和 key）：

```js
const baseUrl = 'http://127.0.0.1:18443/openai/v1';
const apiKey = 'YOUR_BRIDGE_API_KEY';
const response = await fetch(`${baseUrl}/models`, {
    headers: { Authorization: `Bearer ${apiKey}` },
});
const models = await response.json();
console.log(models);
```

- **边界**：这是本机恢复点，不是持续备份或异地备份；聊天、Google 凭据和日志保持原有管理方式。快照包含桥接访问 key，请按敏感配置保管。
- **Luker**：完整 ZIP 选择“设置”可带走这些快照，导回后仍需在 PayGo 中选择应用。

## ❓ 常见问题 (FAQ)

### Q: 为什么界面找不到设置面板，或提示不兼容？

**A**：
- **SillyTavern / Luker**：统一设置入口位于 **扩展程序 → ST-Vertex-PayGo**；服务层级卡片需先在 API 连接设置中选择 **Google Vertex AI** 或 **Google AI Studio** 才会出现。
- **TauriTavern**：菜单位于 **扩展设置 → ST-Vertex-PayGo**，默认折叠，点击标题即可展开。如果提示缺少接口，说明当前所用的 Tauri 构建版本未开启第三方扩展或附加参数权限。

### Q: “服务端插件状态”始终显示未就绪（仅 ST / Luker）？

**A**：请按顺序检查：
1. 后端文件夹是否放在了 `<酒馆根目录>/plugins/ST-Vertex-PayGo-Server/`。
2. 酒馆根目录的 `config.yaml` 中是否已将 `enableServerPlugins` 设为 `true`。
3. 修改配置或放好文件后，必须**彻底关闭并重新启动酒馆终端**。

### Q: 为什么无法勾选 Flex 或 Priority 选项？

**A**：
1. 检查当前模型 ID 是否以 `gemini-` 开头。
2. 检查所选模型是否支持该层级（不支持的模型会被置灰禁用）。
3. AI Studio 官方不提供 Priority 模式。
4. Vertex AI 的 Flex / Priority 强制要求区域设为 `global`，请按照弹窗提示切换区域。

### Q: 为什么非流式模式下的回复显示“部分估算”？

**A**：这是正常现象。在 TauriTavern 等环境下，非流式响应不会回传思考过程产生的 Token 数量。为了避免误导，插件会将其标注为“部分估算”，而不会直接算作 0 元。

### Q: 生成被拦截并提示请求失败，原因在哪里看？

**A**：参数校验、反代冲突或服务端准备失败时，扩展会立即终止生成并显示具体原因，保留服务端错误码和 HTTP 状态。需要更多细节时，管理员可在「常规」标签页查看日志。
